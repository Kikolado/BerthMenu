# StartDock tips

## Opening things

- Just start typing after opening StartDock to search. Enter opens the first result, and the arrow keys move between tiles.
- Alt+1 to Alt+9 open the first nine tiles (or search results). Hold Alt to see which number is which.
- Search also runs commands and opens paths, like the Windows Run box: try cmd, regedit, C:\Users or %AppData%. Ctrl+Shift+Enter runs a command as administrator.
- Type math like 125*4 or 15% of 80 to get the answer. Enter copies it.
- Right-click a search result → Hide from search if you never want to see it. Settings → Search → Manage brings it back.
- Esc closes StartDock.

## Pinning

- Drag files, folders, shortcuts or a browser link onto the dock to pin them. To open StartDock mid-drag, press the Windows key or hold the drag over the Start button for a moment.
- Right-click an empty part of the dock for "Add App or Folder".
- The Add window can also pin any file or shortcut, a folder, or a website.
- Right-click a search result → Pin to StartDock.
- Click a pinned folder to look inside it without leaving the dock. Shift+click opens it in File Explorer.

## Organizing

- Click a category's name to fold it down to just the name. Click again to open it.
- Drag a category's name to move the whole category.
- Drop one tile onto the middle of another to group them into a folder.
- Drag a tile into the empty strip under the last category to start a new category.

## Customizing tiles

- Right-click a tile → Properties... to change what it opens, add arguments, set a "Start in" folder, always run it as administrator, or give it search keywords (like "ps" for PowerShell). Pin the same app twice with different arguments for two versions of it.
- Right-click → Change icon... takes any picture or .ico file. GIFs work!
- Right-click → Refresh icon fixes a blank icon, or puts the app's own icon back after a custom one.
- Select a tile with the arrow keys: F2 renames it and Delete removes it.
- Removed something by mistake? Click Undo at the bottom of the dock, or press Ctrl+Z.
- Right-click an app to see its recent files.
- Turn on Settings → Startup → "Pin to StartDock" in File Explorer to pin files and folders from their right-click menu.

## Settings

- Can't find a setting? Type in the search box at the top of Settings, or press Ctrl+F there.
